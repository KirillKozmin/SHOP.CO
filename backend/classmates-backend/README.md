# classmates-backend

Два учебных бэкенда на FastAPI — по одному на каждый макет Figma. На них студенты учатся работать с бэкендом: каталог, авторизация, корзина.

| Папка | Макет | Порт | Swagger |
|-------|-------|------|---------|
| [`clothes-shop/`](clothes-shop/README.md) | SHOP.CO — магазин одежды | 8000 | <http://localhost:8000/docs> |
| [`electronics-shop/`](electronics-shop/README.md) | cyber — магазин электроники | 8001 | <http://localhost:8001/docs> |

Порты разные — можно запускать оба сразу.

## Запуск

Нужен Python 3.10+. Зайдите в папку нужного бэкенда и запустите:

```bash
cd clothes-shop        # или electronics-shop
./run.sh               # Windows: run.bat
```

Подробности, список полей и примеры запросов — в README внутри каждой папки.

## Что есть в обоих бэкендах

- **Каталог** `GET /products` — пагинация (`page`, `limit`), фильтры, сортировка (`sortBy`, `order`).
- **Авторизация** `POST /auth/register` и `POST /auth/login` — принимают `email` + `password` (+ `name` при регистрации) и возвращают `accessToken`.
- **Корзина** `/cart` — просмотр, добавление, изменение количества, удаление (нужен токен).
- **Картинки товаров** — файлы `static/images/1.png`, `2.png`, … в папке каждого бэкенда; номер в имени файла = поле `image` товара. Сейчас картинки есть у первых 9 товаров каждого магазина, у остальных — `404`, и на фронте нужна запасная картинка. Таблица «товар → картинка» — `IMAGES.md` внутри папки бэкенда.
- Токен доступа живёт 24 часа, после этого методы с токеном отвечают `401` — нужно снова войти (`POST /auth/login`).
- JSON в camelCase, ошибки в виде `{"detail": "..."}`, CORS открыт.
